# Wapbolt Desktop Releases 🚀

Selamat datang di repositori resmi distribusi aplikasi **Wapbolt**. Repositori ini khusus digunakan untuk menampung installer aplikasi Wapbolt versi terbaru untuk semua platform (Windows, macOS, dan Linux).

Wapbolt adalah API Testing, Orchestration & Collaboration platform yang dirancang untuk performa tinggi, kecepatan (*lightning fast*), dan sinkronisasi real-time.

---

## 📥 Download Terbaru (v1.4.3)

Silakan unduh installer sesuai dengan Sistem Operasi Anda melalui link di bawah ini:

| Platform | Format File | Petunjuk |
|---|---|---|
| **Windows** | `.exe` (Setup) | Unduh dan jalankan installer. |
| **macOS** | `.dmg` (Apple Silicon/Intel) | Buka dmg dan drag Wapbolt ke Applications. |
| **Linux** | `.AppImage` / `.deb` | Ubah izin menjadi executable dan jalankan. |

👉 **[Klik di sini untuk melihat semua rilis (RELEASES)](https://github.com/abdullahPrasetio/wapbolt-desktop-releases/releases/latest)**

## 🛠️ Catatan Instalasi

### Windows
Jika Anda melihat peringatan **"Windows protected your PC"** atau **"SmartScreen"**:
1. Klik **"More info"**.
2. Klik **"Run anyway"**.

### macOS
Jika muncul peringatan keamanan:
1. Buka **System Settings** > **Privacy & Security**.
2. Scroll ke bawah dan klik **"Open Anyway"** pada bagian Wapbolt.

Aplikasi Wapbolt dilengkapi dengan fitur pembaruan otomatis. Setiap kali Anda membuka aplikasi, Wapbolt akan mengecek apakah ada versi terbaru di repositori ini.
