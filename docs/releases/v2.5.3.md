# Wapbolt v2.5.3 — Bug Fix & UI Polish

**Tanggal:** 2026-06-08  
**Type:** Patch release (Bug fixes)

---

## Highlights

- **TopNavbar baru** — Tab bar dipindah ke komponen `TopNavbar` tersendiri untuk struktur yang lebih rapi
- **Tombol "+" disembunyikan** saat belum ada tab terbuka, menghindari tampilan yang membingungkan di layar welcome
- **Default header `Content-Type: application/json`** otomatis ditambahkan pada setiap draft request baru
- **Perbaikan TypeScript** — hapus variabel destructuring yang tidak dipakai di `Sidebar` untuk menghilangkan error TS6133

---

## Changes

### Desktop

- `TopNavbar.tsx` — komponen tab bar baru, memisahkan logika navigasi tab dari `MainArea`
- `AppLayout.tsx` — integrasi `TopNavbar` ke layout utama
- `MainArea.tsx` — refactor setelah tab bar dipisahkan ke `TopNavbar`
- `ResponseArea.tsx` — perbaikan tampilan area respons
- `Sidebar.tsx` — hapus variabel destructuring tak terpakai (`_collectionId`, `_parentId`, `_type`) untuk memperbaiki error TS6133
- `useDataStore.ts` — pembaruan store untuk mendukung state tab yang direfactor
- `main/index.ts` — pembaruan konfigurasi window utama

### Perbaikan Detail

| Komponen | Perubahan |
|----------|-----------|
| Tab bar (`TopNavbar`) | Tombol "+" kini hanya tampil saat ada tab aktif |
| Draft request baru | Otomatis mendapat header `Content-Type: application/json` |
| `LoginPage.tsx` | Tambah generic type pada `apiClient.get<T>()` untuk type safety |
| `Sidebar.tsx` | Hapus unused destructured variables, resolve TS6133 |

---

## Bug Fixes

- **[TS6133]** `Sidebar.tsx` — variabel `_collectionId`, `_parentId`, `_type` dari destructuring tidak digunakan, kini dihapus
- **UI** — tombol tambah tab ("+" icon) tidak lagi muncul di layar welcome ketika belum ada tab yang terbuka
- **Type safety** — `apiClient.get` di `LoginPage` kini menggunakan explicit generic type agar tidak ada implicit `any`
- **UX** — request baru tidak perlu lagi menambahkan `Content-Type` secara manual karena sudah di-set default ke `application/json`
