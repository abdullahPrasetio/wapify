# Wapbolt v2.4.0 — OpenAPI Sync to Confluence

**Tanggal:** 2026-05-29  
**Type:** Feature release (P3-2 + OpenAPI Confluence Sync)

---

## Highlights

- **Sync ke Confluence** — Export dokumentasi koleksi langsung ke halaman Confluence dengan 4 mode: Documentation Only, OpenAPI 3.0 (Raw JSON), Swagger UI Interactive, dan Documentation + Swagger UI
- **Swagger UI via macro** — Integrasi native dengan app "Open API (Swagger) Integration for Confluence" menggunakan macro `swagger-open-api` (spec di-embed langsung, tanpa upload attachment)
- **Footer otomatis** — Semua mode sync menyertakan footer generated-by di bagian paling bawah halaman
- **Backend hardening** — 5 unguarded `.(float64)` type assertion di `collection.go` diperbaiki dengan comma-ok pattern

---

## Changes

### Backend

- `collection.go` — Semua 5 handler (`ImportPostman`, `ImportOpenAPI`, `CreateCollection`, `UpdateCollection`, `DeleteCollection`) menggunakan comma-ok pattern pada `c.Locals("user_id").(float64)` — return 401 jika assertion gagal, bukan panic

### Frontend

- `DocumentationPanel.tsx` — Fitur Sync ke Confluence:
  - Mode **Documentation Only**: dokumentasi lengkap (headers, body, cURL, response examples) + footer
  - Mode **OpenAPI 3.0 (Raw JSON)**: raw JSON spec dalam code block + footer
  - Mode **Swagger UI (Interactive)**: macro `swagger-open-api` dengan spec di-embed langsung (tanpa attachment upload)
  - Mode **Documentation + Swagger UI**: gabungan documentation + Swagger UI macro dalam satu halaman, urutan bisa dikonfigurasi
  - `generateFooter()` dipindah ke level atas — selalu ditambahkan di paling bawah terlepas dari mode yang dipilih
  - Opsi SwaggerHub dihapus (macro name belum terverifikasi)

---

## Bug Fixes

- Fixed: macro name Confluence untuk "Open API (Swagger) Integration for Confluence" yang sebelumnya salah (`swagger-integration`) diperbaiki ke `swagger-open-api` sesuai storage format aktual
- Fixed: mode "Documentation + OpenAPI" sekarang menggunakan Swagger UI macro, bukan raw JSON

---

## Security

- `collection.go`: type assertion panic pada `user_id` locals tidak mungkin terjadi lagi — semua handler return 401 dengan pesan `unauthorized` jika middleware tidak menyetel nilai
