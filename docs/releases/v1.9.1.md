# Wapbolt v1.9.1 — GraphQL Support 🔷

GraphQL kini menjadi warga negara kelas satu di Wapbolt. Tidak perlu lagi manual format body JSON — tulis query, isi variables, dan kirim.

---

### ✨ Fitur Baru

#### 🔷 GraphQL Testing

- **Body type baru: GraphQL** — pilih `GraphQL` di tab Body, langsung muncul split editor.
- **Query editor** dengan syntax highlighting GraphQL penuh (Monaco Editor).
- **Variables editor** (JSON) di panel kanan — diparse otomatis ke object saat request dikirim.
- **Operation Name** — input untuk named operations (`query MyOp { ... }`).
- **Load Schema** — fetch schema via introspection (`__schema`) langsung dari endpoint aktif:
  - Menyertakan `args`, `description`, `enumValues`, `inputFields`, `interfaces`, `possibleTypes`
  - Tampil di tab **Schema** di panel kanan untuk referensi saat menulis query
- **Auto-POST** — method otomatis di-override ke `POST` dengan `Content-Type: application/json`.
- **Variables parse otomatis** — JSON string di variables diparse ke object sebelum dikirim, hanya dikirim jika tidak kosong.
- Schema di-reset otomatis saat URL endpoint berubah — tidak ada schema stale.

---

### 🐛 Bug Fixes

- **Load Schema via IPC** — introspection kini dikirim lewat Electron IPC (bebas CORS) bukan `fetch()` langsung dari renderer.
- **Fix stale closure** di GraphQL editor — perubahan query/variables selalu membaca state terbaru, tidak lagi capture nilai lama dari closure.

---

### 🔧 Peningkatan Teknis

- `normalizeRequest` menangani body_type `graphql` — body dinormalisasi ke `{query, variables, operationName}` JSON string.
- `contentTypeMap` di Zustand store menambahkan `graphql → application/json` untuk auto-update header saat switch body type.
- Refactor blok GraphQL di `executeActiveRequest` dari `let` mutable ke `const` + IIFE — lebih aman dan predictable.
