# Wapbolt v2.3.0 — Premium Member Badge & Toggle

**Tanggal:** 2026-05-29  
**Type:** Feature release (P3-1)

---

## Highlights

- **Premium Member Badge** — Crown icon kuning di Sidebar, Header, ActivityLog, dan TeamManagement untuk user premium
- **Premium Toggle** — Admin dapat mengaktifkan/menonaktifkan status premium user langsung dari UserManagement table
- **Premium Thank You Modal** — Klik badge Premium di Sidebar memunculkan pesan terima kasih yang diambil dari backend (`system_settings`)
- **Admin konfigurasi pesan** — DonationSettings panel sekarang termasuk field `Premium Thank You Message`
- **Backend hardening** — `SetUserPremium` diprotect dengan validasi ID + error check; `GetCurrentUser` pakai comma-ok type assertion

---

## Changes

### Backend

- `models.go` — Tambah field `IsPremium bool` dan `PremiumSince *time.Time` ke User model
- `migrations/000029_add_premium_to_users.up.sql` — Migrasi kolom `is_premium` + `premium_since` ke tabel `users`
- `donation.go` — Endpoint baru `GET /api/v1/donations/premium-message` mengembalikan pesan dari `system_settings` (dengan fallback hardcoded)
- `donation.go` — `GetDonationConfig` sekarang include `premium_thank_you_message` dalam response
- `admin.go` — `SetUserPremium`: validasi `id` via `parseUint()`, error check `DB.First` setelah update (return 404 jika user tidak ada)
- `auth.go` — Login & Refresh response sekarang include `is_premium` di user object
- `auth.go` — `GetCurrentUser`: comma-ok pattern pada `c.Locals("user_id").(float64)` — return 401 jika `!ok`

### Frontend

- `types/index.ts` — Tambah `is_premium: boolean` dan `premium_since: string | null` ke interface `User`
- `useAuthStore.ts` — Login dan rehydrateAuth fetch `/auth/me` setelah auth untuk mendapat field terbaru; tambah action `refreshUser()`
- `Sidebar.tsx` — `PremiumBadge` component: fetch pesan dari backend via static `apiClient` (bukan dynamic import)
- `Header.tsx` — Crown icon kuning jika `user?.is_premium`
- `ActivityLogView.tsx` — Crown icon di samping nama sender jika `sender.is_premium`
- `TeamManagement.tsx` — Crown icon di samping nama member di modal Manage Members
- `UserManagement.tsx` — Kolom Premium baru dengan toggle button; `handleTogglePremium` call `PUT /admin/users/:id/premium`
- `DonationSettings.tsx` — Field textarea `Premium Thank You Message` di admin panel

---

- Fixed: `title` prop pada Lucide icon (`Crown`) di Header, ActivityLogView, TeamManagement diganti `aria-label` (TS2322)
- Fixed: Dynamic `import()` di event handler PremiumBadge → static top-level import
