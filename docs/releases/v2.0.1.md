# Wapbolt v2.0.1 — Bug Fixes & Hardening

Patch release berisi perbaikan dari hasil code review fitur-fitur v2.0.0.

---

### 🐛 Bug Fixes

- **File Upload — error handling**: `handleFilePick` di renderer dibungkus `try-catch`; `fs.statSync` di IPC handler juga di-guard — tidak lagi silent failure jika file tidak bisa dibaca (fallback `size: 0`).
- **File dialog — window focus**: `BrowserWindow.getFocusedWindow()` ditambah fallback ke `getAllWindows()[0]` sehingga dialog tetap terbuka meski window kehilangan fokus saat tombol diklik.
- **Response Snapshots — cap maksimum**: Dibatasi 10 snapshot per request. Menyimpan lebih dari batas menampilkan error toast, mencegah memory tidak terbatas.
- **Keyboard icon — custom event**: Tombol keyboard icon tidak lagi men-dispatch `KeyboardEvent` sintetis. Kini menggunakan `CustomEvent('wapbolt:open-shortcuts')` yang di-listen secara eksplisit di MainArea — tidak ada risiko konflik handler.
- **CSP — Monaco workers**: Ditambah `worker-src 'self' blob:` di `index.html` agar Monaco editor dapat membuat web workers tanpa error Content Security Policy.
- **TypeScript — duplicate identifier**: Hapus deklarasi duplikat `responseSnapshots` di `DataState` interface.

### 🔧 Peningkatan Teknis

- `openFileDialog` dan `reloadApp` ditambahkan ke `WapboltAPI` interface di `env.d.ts` — `(window as any).api` cast dihapus sepenuhnya, type-safe penuh.
