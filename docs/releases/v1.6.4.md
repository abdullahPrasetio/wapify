# Wapbolt v1.6.4 — Sidebar Refactor & Improved Save Flow 🚀

Rilis ini fokus pada peningkatan UX secara masif, terutama pada navigasi sidebar, manajemen tab, dan alur penyimpanan request yang lebih intuitif.

### ✨ Apa yang Baru?

#### 🖱️ Sidebar Drag & Drop Refactor
Pengalaman mengatur koleksi kini jauh lebih mulus dan presisi:
- **Intelligent Drop Zones**: Menggunakan algoritma `closestCenter` untuk deteksi drop yang lebih akurat antar folder dan request.
- **Enhanced Visual Indicators**: Garis indikator sorting kini lebih halus (Indigo) dan highlight nesting folder yang lebih jelas.
- **Drag Overlay Ghost**: Menampilkan "ghost item" (nama request/folder) saat proses drag sedang berlangsung untuk visibilitas yang lebih baik.
- **Activation Constraint**: Penambahan delay 300ms pada drag untuk mencegah trigger tidak sengaja saat melakukan klik biasa.

#### 📂 Recursive Folder Tree for Save Flow
Menyimpan draft request ke koleksi kini lebih mudah dengan UI baru:
- **Hierarchical Tree**: Modal penyimpanan kini menampilkan folder dalam bentuk tree rekursif yang bisa di-expand/collapse.
- **Improved Navigation**: Memudahkan pemilihan lokasi penyimpanan jauh di dalam sub-folder koleksi.
- **Automatic Reset**: Pilihan folder otomatis di-reset saat user berpindah koleksi target.

#### 📑 Advanced Tab Management
Manajemen workspace menjadi lebih produktif:
- **Context Menu Tabs**: Kini mendukung "Close Other Tabs", "Close All Tabs", dan "Duplicate Tab".
- **Force Close**: Penanganan penutupan tab yang lebih tangguh untuk mencegah state yang menggantung.

#### 🛡️ Backend Robustness
- **Safe JSONB Conversion**: Implementasi helper `toJSONB` yang lebih cerdas untuk menangani konversi map, array, maupun raw string secara aman tanpa risiko panic di backend.
