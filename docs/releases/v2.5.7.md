# Wapbolt v2.5.7 — Bug Fix & Improvements

**Tanggal:** 2026-06-10  
**Type:** Patch release (Bug fixes)

---

## Highlights

- **Curl import localhost URL** — URL tanpa `http://` prefix (seperti `localhost:3000/...`) kini otomatis di-prefix `http://` saat import curl
- **Crash saat ganti body type** — error `trim is not a function` ketika switch body type sudah diperbaiki dengan type guard yang benar
- **Security update** — axios diupgrade ke ^1.17.0 untuk menutup 7 celah keamanan (highest severity: HIGH)
- **TypeScript deprecation warning** — peringatan `baseUrl` deprecated di tsconfig sudah disuppress

---

## Changes

### Desktop

- `curlParser.ts` — auto-prepend `http://` untuk URL tanpa protokol saat parsing curl command
- `MainArea.tsx` — fix crash `trim is not a function` dengan `typeof body === 'string'` guard; fix `handleBodyTypeChange` agar konversi body array↔string sesuai tipe
- `package.json` — upgrade axios `^1.15.x` → `^1.17.0`
- `tsconfig.web.json` — tambah `"ignoreDeprecations": "5.0"` untuk suppress baseUrl warning

---

## Bug Fixes

- **[Curl Import]** URL seperti `localhost:3000/api` gagal diparse karena parser hanya terima URL dengan prefix `http://`
- **[Body Editor]** Crash `workingRequest.body?.trim is not a function` saat switch dari form-data/urlencoded ke raw body type
- **[Security]** axios ≤1.15.x memiliki 7 known vulnerabilities termasuk severity HIGH
