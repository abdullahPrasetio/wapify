# Wapbolt v2.0.0 — Keyboard Shortcuts, File Upload & Response Compare

Tiga fitur besar yang melengkapi pengalaman testing API: navigasi keyboard penuh, upload file di form-data, dan perbandingan response side-by-side.

---

### ✨ Fitur Baru

#### 🎹 Keyboard Shortcuts Panel (P3-2)

- **Tekan `Shift+?`** atau klik icon keyboard di area header untuk membuka panel daftar shortcut.
- **6 grup konteks**: Global, Request Editor, Tab Navigation, WebSocket, Collection Runner, Modals.
- **Platform-aware**: menampilkan `⌘` di Mac dan `Ctrl` di Windows/Linux secara otomatis.
- Guard aktif: shortcut tidak terpicu saat user sedang mengetik di input, textarea, atau Monaco editor.

#### 📎 File Upload di Form-Data (P3-3)

- **Toggle Text/File per-row**: di body `form-data`, setiap baris punya tombol toggle tipe (T = text, paperclip = file).
- **Native file picker**: klik "Choose File" membuka dialog OS-native via Electron IPC.
- **Nama & ukuran file** otomatis ditampilkan setelah file dipilih.
- **Kirim sebagai multipart**: file dikirim sebagai `ReadStream` — kompatibel dengan semua server yang menerima `multipart/form-data`.

#### 🔍 Response Compare — Diff View (P3-1)

- **Tombol Snapshot** di toolbar response — simpan response saat ini sebagai snapshot bernama.
- **Tombol Compare** muncul otomatis saat ada ≥1 snapshot — buka Monaco Diff Editor side-by-side.
- Bandingkan snapshot mana saja dengan response saat ini atau snapshot lain.
- Tampilkan status code dan response time untuk setiap sisi.
- Snapshot bisa dihapus langsung dari modal Compare.

---

### 🔧 Peningkatan Teknis

- `ResponseSnapshot` interface ditambahkan ke `useDataStore.ts` — state in-memory per requestId.
- `saveResponseSnapshot` dan `deleteResponseSnapshot` ditambahkan ke store.
- File upload menggunakan `ipcMain.handle('wapbolt:open-file-dialog')` + `dialog.showOpenDialog` di main process; renderer memanggil via `window.api.openFileDialog()`.
- `KeyboardShortcutsModal.tsx` dan `ResponseDiffModal.tsx` dibuat sebagai komponen modal baru.
