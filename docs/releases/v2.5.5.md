# Wapbolt v2.5.5 — Bug Fix & Collaboration Polish

**Tanggal:** 2026-06-09  
**Type:** Patch release (Bug fixes)

---

## Highlights

- **Presence & lock tidak nyangkut** — WebSocket kini reconnect dengan identity yang benar saat user ganti akun, sehingga nama lama tidak lagi muncul di "users viewing" dan lock dari sesi sebelumnya otomatis dilepas
- **Google login lebih andal** — Listener OAuth callback dipindah ke level App sehingga tidak pernah terlewat, apapun kondisi halaman yang sedang ditampilkan

---

## Changes

### Desktop

- `websocket.ts` — tambah listener perubahan `auth.user`; jika user berganti akun, WebSocket disconnect dan reconnect dengan identity baru
- `App.tsx` — listener `onGoogleAuthCallback` dipindah ke sini agar selalu aktif selama app hidup
- `LoginPage.tsx` — hapus listener `onGoogleAuthCallback` yang duplikat

---

## Bug Fixes

- **[Collaboration]** Nama user lama (dari sesi sebelumnya) masih muncul di "users viewing" setelah ganti akun
- **[Collaboration]** Request ter-lock oleh user lama karena WebSocket tidak reconnect dengan identity baru saat login ulang
- **[Google OAuth]** Tab browser menutup tapi app tidak login karena IPC callback terlewat saat `LoginPage` unmount
