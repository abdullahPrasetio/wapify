# Wapbolt v2.5.6 — Bug Fix & Windows UI

**Tanggal:** 2026-06-09  
**Type:** Patch release (Bug fixes)

---

## Highlights

- **Presence langsung hilang saat logout** — LEAVE_REQUEST kini dikirim secara eksplisit sebelum WebSocket ditutup, sehingga nama user lama tidak lagi nyangkut di "users viewing"
- **Window controls di Windows** — tombol minimize, maximize, dan close kini tersedia di title bar untuk pengguna Windows

---

## Changes

### Desktop

- `websocket.ts` — kirim `LEAVE_REQUEST` untuk tab aktif sebelum `ws.close()` pada setiap disconnect
- `TopNavbar.tsx` — tambah komponen `WindowControls` (minimize/maximize/close) yang muncul hanya di Windows
- `main/index.ts` — tambah IPC handler `wapbolt:minimize`, `wapbolt:maximize`, `wapbolt:close`
- `preload/index.ts` — expose `minimizeWindow`, `maximizeWindow`, `closeWindow` ke renderer
- `env.d.ts` — tambah type definition untuk window control API

---

## Bug Fixes

- **[Collaboration]** Presence user lama tidak langsung hilang setelah logout karena LEAVE_REQUEST tidak dikirim sebelum disconnect
- **[Windows]** Tombol minimize/maximize/close tidak ada karena `frame: false` tanpa custom title bar
