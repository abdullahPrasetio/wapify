# Wapbolt v1.9.2 — Request Chaining & Schema Validation

Dua fitur yang mempercepat workflow test API: ekstrak nilai dari response langsung ke environment variable, dan validasi struktur JSON response tanpa nulis kode.

---

### ✨ Fitur Baru

#### ⚡ Request Chaining — Variable Extraction Rules (P2-3)

- **Tab Tests → Extract** — panel khusus untuk mendefinisikan extraction rules per-request.
- **Extraction Rule**: isi JSON Path (e.g. `data.token`) + nama environment variable (e.g. `authToken`) → nilai otomatis disimpan setelah response diterima.
- **Toggle per-rule** — aktifkan/nonaktifkan rule tanpa menghapusnya.
- **Extract button di ResponseArea** — shortcut untuk membuat rule langsung dari panel response: klik "Extract", isi path & variable name, klik "Add Rule".
- **Auto-run**: setelah setiap request, semua enabled rules dieksekusi — nilai di-set ke active environment (persisted ke DB via `updateActiveEnvironmentVariable`).
- **Collection Runner** juga menjalankan extraction rules — variable chain antar-request dalam satu run.
- **Badge indicator** di tab Tests menyala jika ada script, extraction rules, atau schema assertions.

#### 🛡 JSON Schema Assertions (P2-4)

- **Tab Tests → Schema** — tambah satu atau lebih JSON Schema assertions per-request.
- **Monaco JSON editor** per-assertion untuk menulis schema (dengan syntax highlighting & IntelliSense).
- **Toggle per-assertion** — enable/disable tanpa menghapus.
- **Integrasi `ajv`** (v6) — validasi dijalankan otomatis setelah response, menggunakan `allErrors: true` untuk menampilkan semua error sekaligus.
- **Hasil masuk ke Test Results tab** — schema assertion failures muncul bersama script test results, dengan detail error path (`dataPath`) dan pesan.
- **Collection Runner** juga menjalankan schema assertions dan mencatatnya ke test results per-request.

---

### 🔧 Peningkatan Teknis

- `ExtractionRule` dan `SchemaAssertion` interface ditambahkan ke `types/index.ts`.
- `WorkingRequest` diperluas dengan `extraction_rules: ExtractionRule[]` dan `schema_assertions: SchemaAssertion[]`.
- `normalizeRequest` memastikan kedua field selalu berupa array (tidak undefined).
- `ApiRequest` di types mendapat optional `extraction_rules?` dan `schema_assertions?` — siap untuk persisted ke backend di versi mendatang.
- `ajv` ditambahkan sebagai dependency.
