## 🔥 Chaos Mode & Error Simulation (Mock Server)

### Chaos Mode (Collection-level)
- Toggle **Chaos Mode** di header MockServerPanel — ikon api beranimasi saat aktif.
- Saat aktif, semua endpoint di collection dipaksa error rate minimum **50%**, mensimulasikan kondisi jaringan tidak stabil.
- Backend cache chaos mode dengan `sync.Map` + TTL 5 detik — tidak ada N+1 DB query per request.

### Error Injection (Per-endpoint)
- Field baru `error_rate` (0–100%) + `error_status_code` (400–599) per endpoint.
- Slider error rate di form endpoint dengan live preview: *"~X% of requests will return 500"*.
- Status code di-clamp ke range valid 400–599 (fallback `500` jika di luar range).
- Badge error rate di `MockEndpointCard` dengan ikon warning.

### Delay Range (Per-endpoint)
- Field `delay_max_ms` baru — pasangkan dengan `delay_ms` untuk simulasi **random delay range**.
- Form endpoint: dua input Min/Max ms; jika max = 0 maka delay fixed.
- Badge di card menampilkan range `200–500ms` atau fixed `200ms`.

## 📋 Mock Request Logs

- Tab baru **"Request Logs"** di MockServerPanel.
- Setiap request ke mock server di-log secara async (goroutine + `recover()` guard) ke tabel `mock_request_logs`.
- Kolom: timestamp, method, path, status code, latency, apakah matched endpoint, apakah injected error.
- Badge "Chaos Injected" (merah) dan "Unmatched" (kuning) untuk filter visual cepat.
- API: `GET /api/v1/collections/:id/mock/logs` (100 log terbaru).

## 🔍 Global Search yang Diperluas (P3-4)

- Search scope diperluas: **requests**, **collections**, **folders**, **environment variables**, **history**, **navigation**.
- Hasil dikelompokkan per kategori dengan heading section.
- **Fuzzy search** — tidak harus exact match, skor relevansi menentukan urutan.
- Navigasi keyboard `↑↓ Enter` bekerja flat across semua grup.
- Env variable result: badge `Global`/env name + preview value.
- History result: subtitle timestamp + response time + status code, action buka history detail.

## 🛠 Fixes & Hardening

- `collectionID` path param divalidasi sebagai `uint` — return HTTP 400 jika invalid.
- Goroutine async log dilindungi `defer recover()` — panic DB tidak crash server.
- `parseUint()` digunakan konsisten di `updateCollectionChaosMode` dan `listMockRequestLogs`.
