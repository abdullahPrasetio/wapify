# Wapbolt v1.6.5 — Context Menu Fix, Save As Flow & Collaboration Notifications 🛠️

Rilis ini fokus pada perbaikan bug kritis yang ditemukan melalui TestSprite, peningkatan aksesibilitas sidebar, dan visibilitas event kolaborasi real-time.

### 🐛 Bug Fixes

#### 📌 Context Menu Positioning (dnd-kit Transform Fix)
- **Root Cause**: dnd-kit menerapkan CSS `transform` pada item yang di-drag, menciptakan *containing block* baru yang merusak posisi `fixed` pada child element (context menu).
- **Fix**: Konversi `ContextMenu` untuk menggunakan `createPortal` — menu kini dirender langsung di `document.body`, melewati semua parent transform/stacking context. Z-index ditingkatkan ke `z-9999`.
- **Dampak**: Context menu folder dan request tidak lagi overlap atau muncul di posisi salah saat sidebar memiliki item yang sedang di-drag.

#### 💾 Save As — Tidak Bisa Dibuka dari Saved Request
- **Root Cause**: Modal `SaveRequestLocationModal` sebelumnya hanya dirender jika `requestId` bertipe string (draft). Request yang sudah tersimpan (integer ID) tidak bisa membuka modal ini.
- **Fix**: Modal kini selalu dirender; kondisi `typeof requestId === 'string'` dihapus. `draftId` untuk saved request di-pass sebagai `saved-{id}`.

#### 📂 Folder Tidak Muncul di Modal Save As
- **Root Cause**: `foldersByCollection` hanya terisi saat koleksi di-expand di sidebar. Koleksi yang belum pernah dibuka tidak memiliki data folder di store.
- **Fix**: Modal kini memanggil `fetchCollectionContents` secara eksplisit saat dibuka (untuk koleksi default) dan saat user mengganti koleksi target.

#### 🔧 `window.api` Crash di Browser Mode
- **Fix**: Penambahan optional chaining `window.api?.getAppVersion()` di Sidebar untuk mencegah crash saat aplikasi dijalankan di browser (bukan Electron).

### ✨ Fitur Baru

#### 🗂️ Folder Action Button (Aksesibilitas TestSprite)
- Tombol tiga titik (`...`) kini muncul di setiap item folder saat di-hover, memicu context menu yang sama dengan right-click.
- Memungkinkan aksi folder (rename, delete, dll.) tanpa memerlukan klik kanan — penting untuk aksesibilitas dan pengujian otomatis.

#### 📋 Duplicate Request dari Request Panel
- Dropdown chevron (`⌄`) di samping tombol **Save** kini membuka menu dengan dua opsi:
  - **Save As...** — menyimpan salinan ke koleksi manapun
  - **Duplicate** — menduplikasi request langsung di koleksi yang sama (hanya muncul untuk saved request)
- Sebelumnya, duplikat hanya bisa dilakukan via right-click di sidebar.

#### 🟢 WebSocket Status Indicator
- Indikator status kolaborasi (`connected` / `connecting` / `disconnected`) kini tampil di sidebar header dengan warna hijau/kuning/merah.
- Status diperbarui setiap 500ms secara real-time.

#### 🔔 Collaboration Events di Notification Bell
- Event koneksi dan rekoneksi WebSocket kini muncul sebagai notifikasi persisten di panel notifikasi (bell icon), tidak hanya sebagai toast yang menghilang.
- Notifikasi dibedakan: **"Collaboration Connected"** untuk koneksi pertama, **"Collaboration Reconnected"** untuk reconect setelah terputus.
- Notifikasi lokal menggunakan ID negatif untuk menghindari konflik dengan ID notifikasi dari server.

### 🔧 Perbaikan Teknis

- **`importCollection` type fix**: Definisi tipe di `useDataStore.ts` disesuaikan agar menerima parameter opsional `mode` dan `confirmName` sesuai implementasi aktual — menghilangkan error `TS2554`.
- **`flattenTree` cleanup**: Fungsi yang tidak terpakai dihapus dari `SaveRequestLocationModal.tsx` — menghilangkan error `TS6133`.
