# Wapbolt v1.6.3 — Confluence Resilience & Variable Resolution 🛠️

Rilis ini membawa peningkatan krusial pada ketahanan konektivitas Confluence, terutama untuk lingkungan korporat dengan firewall ketat, serta dukungan penuh untuk variabel environment.

### ✨ Apa yang Baru?

#### 🛡️ Enterprise Connectivity & Firewall Bypass
Peningkatan stabilitas sinkronisasi Confluence di lingkungan jaringan yang diproteksi ketat (seperti WAF BRI):
- **Method Tunneling Support**: Implementasi `X-HTTP-Method-Override` dan `POST-as-PUT` tunneling untuk melewati blokir firewall terhadap metode HTTP `PUT`.
- **CSRF Protection Bypass**: Penambahan header `X-Atlassian-Token: no-check` untuk memastikan sinkronisasi lancar pada Confluence Server/Data Center.
- **Flexible URL Construction**: Menghapus paksaan konteks `/wiki`, memberikan kontrol penuh kepada pengguna untuk menentukan jalur API yang tepat melalui pengaturan Base URL.

#### 🌍 Full Environment Variable Resolution
Dokumentasi yang dikirim ke Confluence kini jauh lebih cerdas:
- **Dynamic Content**: Placeholder `{{variable}}` pada URL, Headers, Body, dan Deskripsi kini otomatis di-resolve menggunakan nilai dari environment yang aktif sebelum dikirim.
- **Ready-to-Use Docs**: Dokumentasi di Confluence kini menampilkan nilai asli yang siap digunakan oleh tim pengembang lain.

#### 🐛 Stability & Bug Fixes
- **Null-Safe Versioning**: Memperbaiki `TypeError` saat pengambilan versi halaman Confluence jika data tidak ditemukan atau ter-redirect.
- **Improved URL Sanitization**: Pembersihan otomatis trailing slashes pada Base URL untuk mencegah error 404/405.
