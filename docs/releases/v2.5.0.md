# Wapbolt v2.5.0 — Google OAuth Login & Register

**Tanggal:** 2026-06-02  
**Type:** Feature release (Google Sign-In + Docker Enhancement)

---

## Highlights

- **Google Sign-In** — Login dan Register menggunakan akun Google tanpa perlu buat password baru
- **Auto-link akun** — Jika email Google sudah terdaftar, akun otomatis ter-link tanpa buat akun baru
- **Auto-create workspace** — User baru via Google otomatis mendapat personal workspace
- **Toggle via env** — Google OAuth bisa diaktifkan/dinonaktifkan via `GOOGLE_OAUTH_ENABLED` tanpa rebuild

---

## Changes

### Backend

- `auth_google.go` — Implementasi Google OAuth 2.0 flow:
  - `GET /api/v1/auth/google/status` — cek apakah Google OAuth aktif
  - `GET /api/v1/auth/google` — redirect ke halaman login Google
  - `GET /api/v1/auth/google/callback` — handle callback, exchange code, fetch user info, generate JWT
  - `findOrCreateGoogleUser()` — cari by `google_id`, fallback cari by email (link akun), atau buat user baru
  - Deep link callback ke desktop app via `wapbolt://auth/callback?token=...&refresh_token=...`
- `Dockerfile.client` — tambah `curl` untuk debugging koneksi di container
- `Dockerfile.central` — tambah `curl` untuk debugging koneksi di container

### Desktop

- `package.json` — bump version ke `2.5.0`

## Environment Variables Baru

| Variable | Keterangan |
|----------|------------|
| `GOOGLE_CLIENT_ID` | OAuth Client ID dari Google Cloud Console |
| `GOOGLE_CLIENT_SECRET` | OAuth Client Secret dari Google Cloud Console |
| `GOOGLE_REDIRECT_URI` | Callback URL, contoh: `https://yourdomain.com/api/v1/auth/google/callback` |
| `GOOGLE_OAUTH_ENABLED` | Set `true` untuk mengaktifkan Google Sign-In |

---

## API Endpoints Baru

| Method | Endpoint | Keterangan |
|--------|----------|------------|
| GET | `/api/v1/auth/google/status` | Cek apakah Google OAuth aktif |
| GET | `/api/v1/auth/google` | Redirect ke halaman login Google |
| GET | `/api/v1/auth/google/callback` | Callback handler dari Google |
