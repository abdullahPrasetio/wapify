# Wapbolt v2.2.0 — SSE Testing, Timing Chart & Insomnia Import

**Release date:** 2026-05-27

---

## 📡 Server-Sent Events (SSE) Testing

- Protocol toggle baru **SSE** di samping HTTP dan WebSocket.
- Koneksi via browser-native `EventSource` — reconnect otomatis dihandle browser.
- Auto-konversi URL saat switch: `wss://` → `https://`, `ws://` → `http://`.
- Listener untuk named events: `update`, `ping`, `error`, `close`, `data`, `event` via `addEventListener`.
- Status indicator: Disconnected / Connecting / Connected / Error dengan color-coded badge.
- Filter event log by event name (live filter, no re-request).
- Copy event data ke clipboard per-row (hover untuk tampil).
- Tombol **Disconnect** + **Clear Log** di header panel.
- System events (connect/disconnect) ditampilkan italic muted, terpisah dari data events.

---

## ⏱ Response Time Chart (Timing Tab)

- Tab baru **Timing** di ResponseArea — lazy-load history hanya saat tab dibuka.
- SVG sparkline chart (pure, no library) menampilkan 30 run terakhir untuk request aktif.
- Titik berwarna per status code: hijau (2xx), merah (4xx/5xx), kuning (lainnya).
- Stats bar: total runs, min / avg / max response time (ms), jumlah 2xx, jumlah error.
- Scrollable run list di bawah chart: method badge, timestamp, status code, response time.

---

## 📥 Insomnia v4 Import

- Import koleksi dari file export Insomnia v4 (`.json`, `__export_format: 4`).
- Konversi ke format Postman v2.1 di frontend — reuse endpoint `/import` existing tanpa perubahan backend.
- Mendukung tipe body: JSON, URL-encoded, form-data, raw.
- Mendukung auth: Bearer Token, Basic Auth, API Key.
- Struktur folder (request_group) direkonstruksi rekursif ke Postman folder items.
- Preview jumlah endpoint terdeteksi sebelum konfirmasi import.
- Mode import: `new` (koleksi baru) dan `overwrite` (replace koleksi existing).

---

## 🛠 Bug Fixes

- **SSE URL conversion** — switch ke SSE dari WS mode kini konvert `wss://` → `https://` agar EventSource dapat konek.
- **`buildItems()` depth limit** — tambah `MAX_DEPTH = 20` pada rekursi folder builder; mencegah stack overflow pada export corrupt/circular.
- **Insomnia resource shape validation** — setiap item di `resources` divalidasi `typeof _id/name/parentId === 'string'` sebelum diproses; mencegah silent TypeError pada export malformed.
