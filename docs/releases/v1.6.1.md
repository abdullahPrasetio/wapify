# Wapbolt v1.6.1 — Shared Environments & UI Polish 🌍

Rilis ini menghadirkan fitur kolaborasi tingkat lanjut dengan Shared Environments yang memungkinkan tim berbagi variabel di seluruh workspace, serta pembaruan antarmuka pengguna untuk pengalaman navigasi yang lebih bersih.

### ✨ Apa yang Baru?

#### 🌍 Shared Environment Lintas Workspace
Kini Anda tidak perlu lagi menduplikasi variabel yang sama untuk setiap tim:
- **Global / Shared Environments**: Super Admin kini dapat membuat environment yang dapat diakses oleh semua tim di dalam sistem.
- **Logical Grouping**: Daftar environment di Sidebar dan Modal kini dikelompokkan secara rapi antara **Global** dan **Workspace**.
- **Role-Based Protection**: Environment global bersifat *read-only* bagi anggota tim biasa, memastikan variabel infrastruktur penting tetap aman dari perubahan yang tidak disengaja.

#### 👤 New Profile & Navigation Experience
Penyegaran pada area profil pengguna di Sidebar:
- **Avatar Dropdown**: Mengganti teks nama yang padat dengan Avatar Inisial yang elegan.
- **Centralized Settings**: Akses ke App Settings, Change Password, dan Confluence Settings kini dikelompokkan dalam satu menu dropdown yang minimalis.
- **Improved Sidebar Footer**: Memberikan lebih banyak ruang visual pada bagian navigasi utama.

#### 🛠️ Developer Productivity
- **Environment Promotion**: Super Admin dapat mengubah environment tim menjadi global atau sebaliknya hanya dengan satu klik (toggle).
- **Sticky Configuration**: Pengaturan environment global yang tetap konsisten di seluruh sesi penggunaan aplikasi.

### ⚙️ Perubahan Teknis (Backend)
- **Schema Migration v26**: Penambahan kolom `is_global` dan modifikasi relasi `team_id` menjadi *nullable* pada tabel `environments`.
- **RBAC (Role Based Access Control)**: Implementasi middleware proteksi pada level API untuk pengelolaan environment global.
- **Optimized SQL Queries**: Penyesuaian query untuk mengambil data environment gabungan (Team + Global) dalam satu tarikan data yang efisien.
