Request Editor + Response Viewer

Monaco Editor (engine yang sama dipakai VSCode) untuk body dan scripting — syntax highlighting, autocomplete, dan format JSON otomatis. Split-pane layout menampilkan request dan response secara bersamaan.

Monaco Editor Split-pane UI Multiple body types Response pretty-print
Real-time Collaboration

Beberapa anggota tim bisa membuka request yang sama secara bersamaan. Field-level locking mencegah konflik editing — saat satu user mengedit URL, user lain melihat badge "Locked by" secara real-time via WebSocket.

WebSocket Presence indicator Field-level locking Go backend
Mock Server + Chaos Mode

Buat endpoint mock dengan beberapa scenario response yang bisa di-switch manual — 200 Success, 401 Unauthorized, 500 Server Error. Chaos Mode memaksa error rate ≥50% untuk simulasi kondisi buruk tanpa menyentuh backend asli.

Dynamic scenarios Manual switch Chaos mode Request logs
Pre-request & Post-request Script

JavaScript sandbox dengan Wapbolt SDK — set header Authorization otomatis, generate timestamp, validasi response, log ke console. Kompatibel dengan sintaks Postman (pm.*) via alias wap.

JavaScript sandbox wap / pm SDK Moment.js · Lodash Postman-compatible
Export ke 9 Bahasa Pemrograman

Generate code snippet siap pakai dari request aktif — cURL, JavaScript, Go, Python, PHP, Kotlin, Swift, Dart, Java. Environment variable di-resolve ke nilai aktual sebelum di-generate.

9 bahasa target Env var resolved Copy to clipboard Template-based generator
Collection Runner

Jalankan seluruh collection sekaligus secara berurutan — lihat hasil PASS/FAIL per request dengan timing dan detail error. Juga tersedia sebagai CLI binary (wapbolt run) untuk integrasi di CI/CD pipeline.

Sequential execution Test assertions CLI: wapbolt run Export JSON report
Environment Variables

Switch antara Dev, Staging, dan Production dalam satu klik. Variable {"{{variable}}"} di-interpolasi secara real-time di URL, headers, dan body. Unresolved variable ditampilkan dengan warning kuning.

{"{{variable}}"} interpolation Multi-environment Per-workspace Unresolved warning
Infrastruktur
Backend berjalan di STB Android,
diekspos via Cloudflare Tunnel

Zero server cost, zero open port, IP asli tersembunyi. Arsitektur yang sama siap di-deploy on-premise.

Arsitektur: STB Android + Cloudflare Tunnel

Go binary cross-compile ke Android ARM, berjalan di STB (set-top box) Android di rumah. Diekspos via Cloudflare Tunnel tanpa perlu IP publik atau membuka port router.

Go cross-compile ARM Cloudflare Tunnel Zero server cost On-premise ready
On-Premise License + RBAC

Validasi license berbasis Ed25519 digital signature — instalasi on-premise di server client tanpa perubahan kode. Role-based access control dengan 4 level: Owner, Admin, Editor, Viewer.

Ed25519 signature RBAC 4 level Super Admin bypass JWT + refresh token
